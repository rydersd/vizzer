# Planning research

Research supporting area discussions belongs here, grouped by area after the
project has been assigned. Each note should record the originating question,
sources and access dates, findings, conflicting evidence, uncertainties, and
implications for candidate plans. Link back to the discussion and affected plan.
Keep source statements distinct from inference. Preserve rejected approaches and
original rationale for future article writing.

The [planning inbox](../../product-spec/planning/README.md) explains the initial
Codex desktop watch. No research has been commissioned merely by creating this directory.
